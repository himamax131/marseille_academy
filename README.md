# Marseille Academy Website ⚽

موقع أكاديمية مارسيليا لكرة القدم — تصميم عالمي حديث مع أنيميشن ولوحة تحكم.

## المميزات

- **تصميم احترافي عالمي** بألوان مستوحاة من أندية النخبة (أزرق غامق + سماوي)
- **أنيميشن سلس** (loader، particles، reveal on scroll، hover effects)
- **صفحات منفصلة**:
  - الرئيسية: معلومات الأكاديمية + آخر الأخبار
  - المباريات: عرض الفريقين + الشعارات + الإحصائيات
  - الوسائط: عرض أهم البوستات والفيديوهات عبر الروابط
- **لوحة تحكم (Admin)** محمية بكلمة مرور مؤقتة
- **تخزين محلي (localStorage)** حتى إضافة قاعدة بيانات لاحقاً

## طريقة الرفع على GitHub Pages

1. أنشئ مستودع جديد على GitHub (مثلاً `marseille-academy`)
2. ارفع كل محتويات هذا المجلد
3. من Settings → Pages → Source اختر `main` branch و `/ (root)`
4. الموقع سيعمل على: `https://YOUR_USERNAME.github.io/marseille-academy`
